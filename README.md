# CV_Drones_EEA - Computer Vision for Drone Applications

## 🚁 Overview
This repository contains comprehensive computer vision implementations for drone-based applications, focusing on autonomous navigation, object detection, and image processing techniques essential for unmanned aerial vehicle systems.

## 🎯 Project Scope
The project explores advanced computer vision algorithms specifically designed for drone operations, including real-time image processing, object tracking, and autonomous flight control systems.

## 🔧 Key Implementations

### Live Classification Systems
- **MeherNarula_230648_LiveClass1.py**: Real-time object classification for drone navigation
- **MeherNarula_230648_LiveClass2.py**: Advanced live classification with multiple object detection
- **MeherNarula_230648_LiveClass2contour.py**: Contour-based object recognition for aerial imagery

### Computer Vision Modules
- **arucomarkers.py**: ArUco marker detection for precision landing and navigation
- **cameracalibration.py**: Camera calibration algorithms for accurate depth perception
- **contourbasedcontour.py**: Contour analysis for terrain mapping and obstacle detection
- **convolutionlowpass.py**: Signal processing for noise reduction in aerial imaging

### Advanced Processing
- **examdesign1a.py**: Custom examination algorithms for drone vision systems
- **harrypottercloak.py**: Invisibility cloak implementation using background subtraction
- **highpassconvolution.py**: High-pass filtering for edge enhancement in aerial photography
- **houghtransform.py**: Line and circle detection for structural analysis from drone footage

### Object Detection & Tracking
- **imageprocessing.py**: Core image processing utilities for drone applications
- **objectdetection.py**: Multi-object detection and tracking algorithms
- **videoreaddandoutput.py**: Video stream processing for real-time drone operation monitoring

## 🛠️ Technical Stack
- **Python**: Primary programming language for CV implementations
- **OpenCV**: Computer vision library for image processing and analysis
- **NumPy**: Numerical computing for efficient array operations
